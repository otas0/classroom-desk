Classroom Desk 学生端

安装完成。按下面步骤连上教室服务器即可上课。

打开应用 SmartScreen / 未签名安装说明
  1. 打开应用 点上方「打开应用」，或从开始菜单启动「Classroom Desk」。
  2. 扫码或粘贴配置 教师在后台打开「指派学生机」，用本机摄像头扫 QR；扫码失败时可粘贴教师提供的 JSON。
  3. 核对服务器地址 apiBase 须为教师机局域网地址（例如 http://192.168.1.50:8787），不要用 127.0.0.1。
  4. 选身份开课 在「名单」点自己的姓名完成身份确认，然后按老师指示签到、答题。

若 Windows 提示「未知发布者」，见 docs/SMARTSCREEN.md （更多信息 → 仍要运行）。版本请与教师机 /health 中的 studentDesktopVersion 对齐。
