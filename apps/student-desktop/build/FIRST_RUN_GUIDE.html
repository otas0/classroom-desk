Classroom Desk

学生端已安装

打开应用 → 点「一键连教室」→ 选自己的名字上课。

打开应用 SmartScreen 说明
  1. 打开应用 点上方按钮，或从开始菜单启动「Classroom Desk」。窗口在右下角。
  2. 一键连教室（推荐） 教师在「指派学生机」勾选「开放本班一键连班」。学生点「查找教室」→ 认准班名/教师机 →「确认连接」。
  3. 备选：U 盘 / 扫码 U 盘根目录放 classroom-desk-config.json，或扫教师 QR / 粘贴 JSON。禁止 127.0.0.1。
  4. 选身份 在名单点自己的姓名确认，然后按老师指示签到、答题。

未知发布者提示见 SMARTSCREEN.md 。版本须与教师机 /health 的 studentDesktopVersion 对齐。
