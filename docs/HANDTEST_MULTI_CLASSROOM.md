# 多教室同网段手测（房间码 / 显示名 / 下课关连班）

验收「隔壁班不误连」与下课清幽灵讲台。需 **≥2 台教师机（或两进程不同 class）+ ≥1 学生机**，同 L2 / 同 /24。

## 准备

| 角色 | 配置 |
|------|------|
| 讲台 A | 显示名如「机房-A」；班级 A；一键连班开；记下房间码 |
| 讲台 B | 显示名如「机房-B」；班级 B；一键连班开；记下房间码 |
| 学生 | 干净配置或「换教室」清空后再测 |

## 勾选表

| # | 步骤 | 期望 | 操作员 | 日期 | □ |
|---|------|------|--------|------|---|
| 1 | 学生全网发现 | 列表同时出现 A、B；显示名可区分 | | | |
| 2 | 学生点 A 一键连班 | 只进班级 A；presence 落在 A | | | |
| 3 | 学生「换教室」再连 B | 进班级 B；不再挂 A | | | |
| 4 | 手输 **A 的房间码**（访客隔离场景） | 解析到 A 的 API；不落到 B | | | |
| 5 | 故意输错房间码多次 | 有失败提示；（若已上线鉴权）触发限速 | | | |
| 6 | 讲台 A **下课 / 关一键连班** | 学生再扫：A 不再「可一键」或从优先列表消失 | | | |
| 7 | `student_easy_join_auto_off` 开着时结束深锁 | 一键连班自动关；审计有记录 | | | |
| 8 | mDNS（同 L2） | browse 到 `_classroomdesk._tcp`；TXT 含 displayName/roomCode | | | |

## 不做

- 不要求跨 VLAN 广播互通（跨网段用手输房间码 / 联邦登记）。
- 不录隐蔽采集类证据。
