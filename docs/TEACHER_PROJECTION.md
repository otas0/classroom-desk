# 教师投影模式（LiveBoard）

上课台点击 **投影全屏** 后，侧栏隐藏，只保留大屏答题态势。

## 快捷键

| 键 | 作用 |
|---|---|
| `Esc` | 退出投影（若处于浏览器全屏，会先退出全屏再退出投影） |
| `F` | 切换浏览器全屏（`requestFullscreen`） |

投影顶栏也有「退出投影（Esc）」「全屏（F）」按钮，无键盘时可用。

## 使用建议

1. 投屏线接好后，教师机浏览器打开 `/admin`，进 **上课** → **投影全屏**。
2. 按 `F` 进入全屏，避免浏览器地址栏占高度。
3. 下课按 `Esc` 回到上课台。
4. 收卷 / 错题重练按钮在投影中仍可用；若班级人数多，优先看进度条与正确率。
